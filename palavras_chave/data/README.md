# Stopwords em português

`stopwords_pt.txt` contém 203 palavras da lista pública do projeto Snowball:
https://snowballstem.org/algorithms/portuguese/stop.txt

Cópia obtida em 24/11/2026. Foram removidos apenas comentários, linhas vazias e
eventuais duplicatas, preservando as palavras e a ordem de origem.

A aplicação normaliza a lista com as mesmas regras usadas na comparação dos
tokens. O arquivo acompanha o código para que a análise funcione sem downloads
ou acesso à rede após a instalação das dependências.
